For You

Recommendations based on your Stremio library and watch history.

First: a free TMDB key

For You gets its movie and show data from TMDB. A personal key is free and takes a couple of minutes:

  1. Create a free TMDB account and confirm your email.
  2. Open API settings and click Create. For the form: type of use Personal, application URL https://github.com/Joshuabastiaans/stremio-for-you, and a summary like "Personal Stremio recommendations addon".
  3. Copy the API Key (or the long API Read Access Token) and paste it below.

You sign in directly with Stremio from this page. Your password never reaches this addon's server.

Open web.stremio.com while signed in, press F12, and run this in the Console:
JSON.parse(localStorage.getItem("profile")).auth.key

"Recommended for You" is always on.

Install in Stremio

Button doesn't open Stremio? Install it by hand:

  1. Click Copy below.
  2. In Stremio, open Addons.
  3. Paste into the search box at the top, press Enter, and click Install.

Start with Stremio

Right now For You only works while ForYou.exe is open. Turn this on and your Stremio shortcuts (Start menu, taskbar, desktop) start For You in the background and stop it when Stremio closes.

This URL contains your login key. Anyone who has it can access your Stremio account, so treat it like a password.

Want different settings? and reinstall.
